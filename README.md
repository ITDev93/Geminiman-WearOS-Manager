## ❓ What is Geminiman WearOS Manager?

**Geminiman WearOS Manager** is an Android application designed to make ADB management for Wear OS devices easier, faster, and more accessible.

ADB is extremely powerful, but many everyday operations normally require a computer, a terminal, and commands that users have to remember or look up.

Geminiman WearOS Manager brings those operations together in a purpose-built interface so you can spend less time typing commands and more time actually managing your watch.

It can be useful whether you are:

* customizing your own Wear OS watch;
* sideloading applications;
* debloating unwanted packages;
* troubleshooting an app;
* collecting logs;
* moving files;
* recording the watch screen;
* or running your own ADB shell commands.

## 🛠️ Features

### 📦 App Management

* Install APK files
* Install split APK packages
* Install APKS and compatible ZIP packages
* Uninstall applications
* Reinstall removed packages
* Disable packages
* Enable packages
* Debloat unwanted applications
* Pull installed APKs from the watch

### 📁 File Operations

* Push files to your Wear OS device
* Pull files from your Wear OS device
* Retrieve APKs, logs, recordings, and other files
* Perform supported backup and restore operations

### 💻 ADB Shell

Built-in actions are convenient, but they cannot cover every possible ADB command.

The shell tools let advanced users run their own commands when they need more control.

### 🎥 Screen Recording

Record the Wear OS screen directly through ADB and retrieve the resulting recording afterward.

Useful for:

* bug reports;
* tutorials;
* demonstrations;
* testing;
* development.

### 📋 Logs & Diagnostics

Create and collect useful troubleshooting information, including Logcat output and other device diagnostics.

This can help both when troubleshooting Geminiman WearOS Manager itself and when investigating problems with other Wear OS applications.

### 💾 Backup & Restore

Access supported backup and restore functionality without manually constructing the required ADB commands.

Some operations may depend on the Android or Wear OS version because Google continues to change platform-level backup and security restrictions.

## ⚡ Built for Simplicity Without Removing Power

Geminiman WearOS Manager is not intended to replace ADB with a collection of overly simplified buttons.

Instead, it provides an easier way to access common operations while still keeping advanced tools available when you need them.

You can use the ready-made tools for everyday tasks and move to shell commands when you want full control.

## 🌍 Languages

Geminiman WearOS Manager includes multilingual support across the application.

You can allow the app to follow the language configured on your device or manually choose a supported language.

Translations are maintained as part of the project so the interface, instructions, dialogs, and tools remain understandable across languages rather than relying on untranslated or hardcoded interface text.
